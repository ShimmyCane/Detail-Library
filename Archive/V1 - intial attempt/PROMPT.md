# Offline Local PDF Detail Library MVP

## Overview
A 100% offline local Desktop Web application using Python (Streamlit), PyMuPDF, and SQLite to catalog, manually tag, search, and visually review PDF architectural/engineering details.

## Deliverables
1. `requirements.txt`
2. `core/db_manager.py`
3. `core/pdf_viewer.py`
4. `app.py`
